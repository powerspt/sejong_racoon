# 라쿤봇 로봇팔과 AI — 수업 자료

세종SW교육체험센터 피지컬 AI 과정. 로보메이션 **라쿤봇** 4축 로봇팔로
좌표계 → 순기구학 → 작업 공간 → 집기 → 작업 지도 → 프로젝트를 다루는 9차시 수업이다.

## 웹 교재

**https://powerspt.github.io/sejong_racoon/** — 학생용 · 교사용 중 하나를 고르고, 목차에서 주제를 눌러 들어간다.
교사용은 학생용과 같은 내용에 슬라이드마다 발표자 노트가 붙어 있다.

## 받기

오른쪽 위 **Code → Download ZIP** 으로 받아 압축을 푼다.

## 처음 한 번

1. 파이썬 3 을 설치한다.
2. `설치/라쿤봇_설치_도우미.bat` 을 두 번 눌러 실행한다 — 라쿤봇 모듈(roboid)을 깐다.
   직접 깔려면 `python -m pip install -r requirements.txt`.
3. 자율 탐구 ③ 손동작을 하려면 `설치/손동작_설치_도우미.bat` 도 실행한다.

## 폴더

| 폴더 | 무엇 |
| --- | --- |
| `가이드/` | 웹 교재 — `학생용/` · `교사용/` (브라우저로 `index.html` 을 열어도 된다) |
| `코드/학생용/` | 학생에게 나눠 주는 코드 — `lessons` · `extras` · `vision` · `docs` |
| `코드/교사용/` | 학생용 전부 + `lessons/*_완성.py` + `examples/` — 이 폴더 하나로 다 돌아간다 |
| `활동지/` | 삼각비 활동지 · 프로젝트 활동지 (HTML · PDF), 활동지 제작 가이드 |
| `작업지도/` | 작업 지도 A3 · B4, 활동별 배치 지도 — 인쇄해서 로봇 밑에 깐다 |
| `설치/` | 설치 도우미 |

## 코드 실행

* 파일을 **IDLE 이나 Thonny 로 열고 F5** 로 실행한다.
* `extras/` 의 활동은 `_가상` 파일로 로봇 없이 먼저 돌려 본다. 로봇으로 돌릴 때는 `_실기기` 파일을 쓰고, 같은 폴더의 `_가상` 파일과 함께 둔다. 폴더마다 `실행방법.txt` 가 있다.
* 바꿔 볼 값은 파일 맨 위 설정 칸에 모여 있다. 파일 맨 아래 '로봇을 움직이는 부품' 은 고치지 않는다.
* 실기기로 돌리기 전에 팔 주변 30cm 를 비운다.
