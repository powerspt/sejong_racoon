# 라쿤봇 로봇팔과 AI — 수업 자료

세종SW교육체험센터 피지컬 AI 과정. 로보메이션 **라쿤봇** 4축 로봇팔로
좌표계 → 순기구학 → 작업 공간 → 집기 → 작업 지도 → 프로젝트를 다루는 9차시 수업이다.

## 받기

오른쪽 위 **Code → Download ZIP** 으로 받아 압축을 푼다. (git 을 쓰면 `git clone` 해도 된다.)

## 처음 한 번

1. 파이썬 3 을 설치한다.
2. `설치/라쿤봇_설치_도우미.bat` 을 두 번 눌러 실행한다 — 라쿤봇 모듈(roboid)을 깐다.
   직접 깔려면 `python -m pip install -r requirements.txt`.
3. 자율 탐구 ③ 손동작을 하려면 `설치/손동작_설치_도우미.bat` 도 실행한다.

## 가이드부터 연다

**`가이드/index.html`** 을 브라우저로 연다. 주제마다 한 파일이고, 수업 슬라이드를 위에서 아래로 읽어 내려가며 따라 할 수 있게 옮겼다.

| 가이드 | 차시 |
| --- | --- |
| 주제 1 로봇팔과 좌표계 | 1 |
| 주제 2 각도에서 좌표로 | 2 |
| 주제 3 작업 공간 | 3~4 |
| 주제 4 집기 시퀀스 | 5~6 |
| 주제 5 작업 지도 위에서 일하기 | 7~8 |
| 주제 6 실생활 문제 해결 프로젝트 | 9 |
| 자율 탐구 ①~④ 영상 처리 · 객체 인식 · 손동작 · 음성 | 프로젝트에 붙이기 |
| 부록 오차와 한계의 과학 | 심화 |

## 폴더

| 폴더 | 무엇 |
| --- | --- |
| `가이드/` | 주제별 가이드 (HTML) |
| `활동지/` | 삼각비 활동지 · 프로젝트 활동지 (HTML · PDF), 활동지 제작 가이드 |
| `작업지도/` | 작업 지도 A3 · B4, 활동별 배치 지도 — 인쇄해서 로봇 밑에 깐다 |
| `lessons/` | 주제 1~5 수업 코드 (`_기본` 은 그대로 실행, `_실습` 은 TODO 를 채운다) |
| `extras/` | 활동 코드 — 폴더마다 `실행방법.txt` 가 있다 |
| `examples/` | 연결 확인 · 관절 · 좌표 이동 · 집기 예제 |
| `vision/` | 자율 탐구용 카메라 · 손동작 코드 |
| `docs/` | 라쿤봇 파이썬 명령 정리, 오차와 AI, 손동작 · 음성 안내 |
| `설치/` | 설치 도우미 |

## 코드 실행

* 파일을 **IDLE 이나 Thonny 로 열고 F5** 로 실행한다.
* `extras/` 의 활동은 `_가상` 파일로 로봇 없이 먼저 돌려 본다. 로봇으로 돌릴 때는 `_실기기` 파일을 쓰고, 같은 폴더의 `_가상` 파일과 함께 둔다.
* 바꿔 볼 값은 파일 맨 위 설정 칸에 모여 있다. 파일 맨 아래 '로봇을 움직이는 부품' 은 고치지 않는다.
* 실기기로 돌리기 전에 팔 주변 30cm 를 비운다.
