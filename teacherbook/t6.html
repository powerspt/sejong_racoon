실제 구분 차시보다 많은 시간이 소요될 수 있음.

비교와 이동, 뭐가 비쌀까? [미션] 로봇으로 정렬하기 · 03_정렬_실연.py

03_정렬_실연.py — 뒤섞인 블록 [4,3,2,1] 을 로봇이 정렬한다.

로봇은 번호를 보지 못한다 — 블록을 놓은 순서를 실행할 때 입력해 알려 준다 (예: 4321).

S/W상의 계산(if문으로 값 비교하기)은 저렴하고, H/W 동작(블록끼리 자리 교환하기)은 비싸다고 가정해보자.

실행 전에 예상부터: 교환 동작은 몇 번 나올까? ___ 회

실행한 뒤: 화면의 비교·교환 횟수와 소요 시간을 표에 적는다 (실제 로봇은 시간을 초시계로 잰다).

— 두 정렬의 시간을 가르는 것은 비교일까, 교환일까?

준비물 — 번호 블록 4개 (3cm, 스티커 1~4)

같은 결과, 세 배 차이 — 비교 횟수는 같았는데 이동(교환) 횟수가 갈랐다.

교환 1회 = 집기 3번(옮기고, 메우고, 되돌리고) — 비교는 if 한 줄인데 교환은 로봇이 세 번 움직인다.

이동이 비싼 세계에서는 알고리즘 선택이 곧 시간이다.

그런데 이동을 줄이는 길이 하나 더 있다 — 횟수가 아니라 거리. 자석 경주에서 잰다.
