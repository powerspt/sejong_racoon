# 주제 8 손동작 인식 — 코드 안내

> 2026-10-16 구현. 설계 근거는 `gesture_control_design.md`.
> MediaPipe 1.0 **Tasks API** 전용이다. 인터넷 예제의 `mp.solutions.hands` 는 이 버전에 없다.

---

## 1. 파일 — 세 층으로 나눠 두었다

```
    [웹캠 화면]
         ↓
  hand_tracker.py    1층 인식   화면 한 장 → HandSignal (손이 보이는가 / 어떤 모양 / 어디)
         ↓
  gestures.py        2층 의도   HandSignal 의 흐름 → Command (집기 · 놓기 · 조종 …)
         ↓
  gesture_control.py 3층 동작   Command → 라쿤봇 팔
```

| 파일 | 하는 일 | 로봇 |
| --- | --- | --- |
| `vision/hand_tracker.py` | 손 21점·제스처 7종 인식, 모델 자동 내려받기, 그리기 도우미 | 불필요 |
| `vision/gestures.py` | 디바운스·길게 누르기·조종 모드·안전(손 사라지면 정지) | 불필요 |
| `vision/hand_test.py` | **15차시 실습 1** — 손에 점이 붙는 것을 확인 | 불필요 |
| `vision/hand_ar.py` | **체험** — 풍선 터뜨리기, 블록 끌기, 손끝 그림 | 불필요 |
| `vision/gesture_control.py` | **16차시 실기** — 손동작으로 팔 조종 | 필요 (`--dry-run` 이면 불필요) |
| `vision/models/` | `gesture_recognizer.task` (8.4MB) 가 여기 들어간다 | — |

층을 나눈 이유는 **갈아끼우기 위해서**다. 인식이 마음에 안 들면 1층만, 제스처 어휘를 바꾸려면
`config.py` 의 표 한 줄만, 로봇 동작을 바꾸려면 3층만 고친다.

## 2. 수업 순서

| 단계 | 명령 | 확인할 것 | 로봇 |
| --- | --- | --- | --- |
| 0 | `학생용\손동작_설치_도우미.bat` | mediapipe 설치 + 모델 내려받기 | — |
| 1 | `python vision/hand_test.py` | 손에 점 21개, 모양 이름, 확신도 | 없음 |
| 2 | `python vision/hand_ar.py` | 풍선·블록·그림. **핀치 임계값을 바꿔 본다** | 없음 |
| 3 | `python vision/gesture_control.py --dry-run` | 콘솔에 `[dummy] close gripper` 등이 찍힌다 | 없음 |
| 4 | `python vision/gesture_control.py` | 이산 명령(집기·놓기·홈)만 먼저 | **실기** |
| 5 | 같은 명령 + 검지 조종 | `TRACK_GAIN_*` 을 +/- 키로 맞춘다 | **실기** |

카메라가 없어도 1~3단계의 동작을 확인할 수 있다.

```
python vision/hand_tracker.py                 모델·인식기 점검
python vision/hand_tracker.py --image 손.jpg  사진 한 장으로 인식
python vision/gestures.py                     디바운스 규칙 자동 점검 (손 모양 대본)
python vision/hand_test.py --image 손.jpg     결과를 png 로 저장
python vision/hand_ar.py --selftest 손.jpg    AR 화면을 png 로 저장
python vision/gesture_control.py --selftest   가상 팔로 흐름 확인
```

## 3. 손 모양과 명령

| 손 모양 | 명령 | 언제 나가는가 |
| --- | --- | --- |
| ✋ 손바닥 `Open_Palm` | 정지 + 조종 해제 | 모양이 바뀌는 순간 한 번 |
| ✊ 주먹 `Closed_Fist` | 집기 | 한 번 |
| ✌ 브이 `Victory` | 놓기 | 한 번 |
| ☝ 검지 `Pointing_Up` | 조종 — 손을 움직이면 팔이 따라온다 | 유지하는 동안 계속 |
| 👍 엄지 위 `Thumb_Up` | 홈 복귀 | **1.5초 유지해야** |
| 👎 엄지 아래 `Thumb_Down` | 관측 자세 | **1.5초 유지해야** |
| 손이 안 보임 | 정지 | 3프레임 뒤 |

바꾸려면 `vision/config.py` 의 `GESTURE_MAP` 한 줄만 고친다.

## 4. 학생이 바꿔 볼 숫자

### `vision/config.py`

| 값 | 기본 | 바꾸면 |
| --- | --- | --- |
| `STABLE_FRAMES` | 5 | 작게 → 반응이 빠르지만 헛 명령이 늘어난다 |
| `HOLD_FRAMES` | 45 | 길게 누르는 시간 (30프레임 ≈ 1초) |
| `LOST_FRAMES` | 3 | 손이 잠깐 가려도 안 멈추게 하려면 크게 — **대신 위험해진다** |
| `GESTURE_MIN_SCORE` | 0.55 | 높이면 확실할 때만 인식한다 (대신 잘 안 잡힌다) |
| `TRACK_GAIN_X/Y` | 24 / 18 | 조종 민감도. 실행 중 `+` `-` 키로도 바꾼다 |
| `TRACK_MAX_STEP_CM` | 2.0 | 한 프레임에 움직일 수 있는 최대 거리 (안전) |

### `vision/hand_ar.py` 맨 위

`PINCH_ON` / `PINCH_OFF` / `BALLOON_*` / `BLOCK_SIZE` / `TRAIL_MAX`

> **수업 포인트** — AR 화면 아래의 막대가 `엄지-검지 거리 ÷ 손 크기` 다.
> 빨간 선(임계값)보다 작아지면 "집었다" 로 판정한다. `[` `]` 키로 선을 움직이면
> 같은 손동작인데 판정이 달라진다. 집었는지를 정하는 것은 AI 가 아니라 **사람이 정한 숫자 하나**다.
> 주제 6의 HSV 여섯 숫자, 주제 7의 신뢰도 임계값과 같은 이야기다.
>
> 왜 거리를 손 크기로 나누는지도 짚어 둘 것 — 손이 멀어지면 모든 거리가 같이 작아진다.
> 나눠 두면 멀든 가깝든 같은 기준으로 볼 수 있다(정규화).

## 5. 교실 준비

- **모델 파일 사전 배포.** 16대가 동시에 받으면 교실 와이파이가 죽는다.
  교사 PC 에서 한 번 받은 뒤 `vision/models/gesture_recognizer.task` 를 USB 로 복사하거나,
  `학생용/설치파일/` 폴더에 같은 파일을 넣어 두면 도우미 배치가 복사해 쓴다.
- **카메라.** 사람 쪽을 보는 웹캠이다. 팔 카메라(`CAMERA_INDEX = 2`)와 다른 장치이고,
  `config.HAND_CAMERA_INDEX` 로 번호를 정한다. 노트북 내장 웹캠은 보통 0 번이다.
- **거울 보기.** `HAND_FLIP_HORIZONTAL = True` 가 기본이다. 좌우가 반대로 느껴지면 끈다.
- **조명.** 역광(창문을 등지고 앉기)이면 손이 검게 나와 인식률이 크게 떨어진다.
  16차시 공정성 측정에서 조건으로 쓸 수 있다.

## 6. 안 될 때

| 증상 | 원인과 조치 |
| --- | --- |
| `ModuleNotFoundError: mediapipe` | `학생용\손동작_설치_도우미.bat` 실행 |
| `AttributeError: module 'mediapipe' has no attribute 'solutions'` | 인터넷 예제를 쓴 것이다. 1.0 에는 없다 — 이 저장소 코드를 쓴다 |
| 모델을 못 받는다 | 학교망 차단. 다른 PC 에서 받아 `vision/models/` 에 복사 |
| 카메라가 안 열린다 | `python vision/hand_ar.py --index 1` 처럼 번호를 바꾼다 |
| 창은 뜨는데 손을 못 찾는다 | 역광·너무 어두움·손이 너무 멀다. `GESTURE_MIN_SCORE` 를 낮춰 본다 |
| 한글이 네모로 보인다 | `pillow` 미설치 또는 맑은 고딕 없음. 도우미 배치가 같이 설치한다 |
| 느리다 (10fps 미만) | 다른 프로그램을 끈다. `HAND_FRAME_WIDTH/HEIGHT` 를 낮춘다 |
| 팔이 덜컥거린다 | `TRACK_MAX_STEP_CM` 을 줄이고 `TRACK_GAIN_*` 을 낮춘다 |

## 7. 안전

- 실기에서는 **로봇이 사람 손 쪽으로 움직인다.** 팔 주변 30cm 를 비운다.
- 손바닥을 들면 즉시 정지, 손이 화면에서 사라져도 정지한다 — **인식 실패의 기본값은 정지**.
- 키보드 백업이 항상 우선이다. 창에 포커스를 두고 **스페이스 = 정지**, **q = 종료**.
- 조종 모드는 꺼진 채 시작한다. 검지를 세워야 켜진다 — 손을 드는 것만으로 팔이 따라오지 않는다.
