# 교사용 코드

이 폴더 하나로 수업 코드 전부가 돌아간다. 학생용(`코드/학생용/`)에 아래 두 가지가 더 들어 있다.

| 더 들어 있는 것 | 무엇 |
| --- | --- |
| `lessons/*_완성.py` | 주제 2 · 3 완성본 — 기본본이 일부러 뺀 것을 채우고 결과를 해석까지 한다 |
| `examples/` | 실기기 점검(07 · 08 · 09)과 조종 도구(05 · 06). `vision/` 을 불러 쓰므로 폴더 구조를 그대로 둔다 |

## lessons 의 세 단계

| 파일 | 언제 | 성격 |
| --- | --- | --- |
| `NN_주제_기본.py` | 수업 시작 | 그대로 실행하면 돌아간다. 핵심 흐름만 |
| `NN_주제_실습.py` | 실습 | 핵심 한두 줄이 `TODO` 로 비어 있다 |
| `NN_주제_완성.py` | 학생이 스스로 해 본 뒤 | 검증 · 오차 분석 · 한계 확인까지 넣은 완성본 |

`_완성` 은 학생에게 먼저 주지 않는다. 학생용 폴더에는 들어 있지 않다.

주제 2 예 — 기본본은 집게 아래 오프셋 0.6cm 를 일부러 빼서 모든 자세에서 6mm 가 똑같이 어긋난다.
학생이 이 규칙성에서 "상수 오차 = 오프셋" 을 찾아낸 뒤 완성본(차이 0.00mm)을 보여 준다.
