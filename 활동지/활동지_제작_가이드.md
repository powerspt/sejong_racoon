# 활동지 제작 가이드

이 과정의 활동지는 **A4 한 장 = HTML 한 쪽**으로 만들고, 크롬에서 PDF 로 인쇄해 나눠 준다.
지금 있는 활동지 두 개를 본보기로 삼아 같은 틀로 만든다.

| 파일 | 쓰는 곳 |
| --- | --- |
| `삼각비_활동지.html` · `.pdf` | 주제 2 「활동지로 직접 재보기」(통합본 33장) |
| `프로젝트_활동지.html` · `.pdf` | 주제 6 프로젝트 — 덱 눈표의 「활동지 ①칸」~「⑩칸」(통합본 123~135장) |

---

## 1. 덱과 짝을 맞춘다

* 덱의 눈표(제목 오른쪽 위 작은 글)에 **「활동지 ○칸」** 이 적혀 있으면, 활동지의 칸 번호와 제목을 그 눈표와 똑같이 쓴다.
  예 — 덱 129장 눈표 `활동지 ⑤칸 · 가상 모드` ↔ 활동지 `5 가상 모드 확인`.
* 덱에 적힌 순서대로 칸을 놓는다. 학생은 슬라이드를 넘기며 활동지를 위에서 아래로 채운다.
* 칸 머리 오른쪽(`.when`)에 **언제 채우는지** 적는다 — `설계 · 12분`, `검증 · 15분` 처럼.
* 덱 문구를 고치면 활동지도 같이 고친다. 반대도 같다.

## 2. 글쓰기

* 이다체 평서형으로 쓴다 — "적는다", "표시한다", "바꿔 본다". 해요체·합니다체는 쓰지 않는다.
* 칸 제목 뒤 힌트(`.hint`)는 한 줄로 무엇을 적는지만 쓴다. 왜 좋은지 설명하는 문장은 넣지 않는다.
* 기록은 **숫자로** 받는다. "잘 됐다" 대신 `8 / 10`, `2mm`, `31초` 가 들어갈 자리를 만든다.
* 예상과 결과를 따로 적는 칸을 둔다 — 실행 **전에** 예상부터 적게 한다.
* 점수·배점은 적지 않는다 (특강 과정).

## 3. 틀 (프로젝트_활동지.html 에서 가져다 쓴다)

```html
<div class="page">                       <!-- A4 한 쪽 -->
  <div class="head">
    <div class="t"><span>주제 2</span>활동지 제목</div>
    <div class="n">반 ___ 번 ___ 이름 ______</div>
  </div>
  <p class="lead">이 활동지를 언제, 어떻게 채우는지 두 줄 안으로.</p>

  <div class="sec">
    <h2><span class="no">1</span>칸 제목 <span class="hint">— 무엇을 적나</span><span class="when">언제 · 몇 분</span></h2>
    <table>…</table>                      <!-- 기록표 -->
  </div>

  <div class="foot">…</div>               <!-- 쪽 번호 · 과정 이름 -->
</div>
```

| 부품 | 쓰임 |
| --- | --- |
| `.w` · `.w.sm` | 점선 한 줄 (7mm · 6mm) — 짧은 답 |
| `.box` | 테두리 상자 — 그림이나 긴 답 |
| `table` + `td.fill` | 기록표. 칸 높이는 `td.fill` 로 정한다 (기본 9mm) |
| `.row` | 두세 칸을 가로로 나란히 |
| `.opts` + `.chk` | 체크 상자 목록 (두 줄 격자) |
| `.stamp` | 교사 확인 도장 칸 |
| `.warn` · `.tip` | 주의(빨강) · 도움말(초록) 띠 |
| `.note` | 칸 아래 작은 설명 |

* 한 쪽에 칸이 넘치면 줄이지 말고 `.page` 를 하나 더 만든다.
* 손으로 적는 칸은 최소 7mm 높이를 준다. 표의 숫자 칸은 9mm.
* 색은 본보기 두 개에 있는 것만 쓴다 — 남색 `#16212e`, 초록 `#2e9e8f`, 빨강 `#c6402f`, 회색 `#5a6675`.

## 4. PDF 로 뽑기

크롬에서 HTML 을 열고 **인쇄 → PDF로 저장 → 여백 없음 · 배경 그래픽 켬** 으로 저장한다.
명령으로 뽑으려면:

```
"C:\Program Files\Google\Chrome\Application\chrome.exe" --headless=new --disable-gpu --no-pdf-header-footer --print-to-pdf="삼각비_활동지.pdf" 삼각비_활동지.html
```

뽑은 뒤 PDF 를 열어 쪽 수와 잘린 칸이 없는지 본다. HTML 과 PDF 는 같은 이름으로 나란히 둔다.

## 5. 아직 파일이 없는 양식 — 덱에 나오는 것

덱에는 기록을 적게 하는 자리가 더 있다. 지금은 슬라이드 안의 표로만 있고 따로 나눠 주는 활동지는 없다.
활동지로 만들 때는 아래 장의 표를 그대로 옮긴다.

| 차시 | 덱(통합본) | 적는 것 |
| --- | --- | --- |
| 1 | 10장 연결하고 상태 읽기 | 배터리 · 신호 · 관절 각도 4개 · 그리퍼 끝 좌표 |
| 1 | 14~16장 좌표계 정의서 | 원점 · +x · +y 정의와 `degree_to(1, 45)` 예상/결과 |
| 1 | 20장 오늘의 활동 정리 | 개발 일지 (기대 / 실제 / 조치) |
| 2 | 25~27장 미션 1~3 | 찾은 각도 · `xyz()` 실측 · 다시 실행한 횟수 |
| 2 | 28장 자세를 상상하고 실행해보기 | 예상 y · z 와 실측, 차이 |
| 3 | 46장 갈 수 있을지 O/X 예상하기 | 좌표 네 개의 예상 O/X 와 확인 결과 |
| 3 | 49장 관절은 어디까지 움직일까? | 관절별 내가 찾은 범위 |
| 4 | 59~66장 단면도 | 작업 공간 단면도 9장 + 경계 원인 기록 |
| 4 | 71장 한 줄 바꿔 고장내기 | 변형 ①②③ 의 내 예상 · 실제 |
| 5 | 95장 다음 시간에 잴 세 가지 | 질문 세 개에 대한 내 예상 |
| 6 | 97~98장 반복정밀도 · 접근 방향 | 열 번 찍은 점의 평균 위치 · 최대 편차(mm) |
| 7 | 100장 비교와 이동 | 알고리즘별 비교 · 교환 횟수 · 소요 시간 |

## 6. 내보내기 전에

- [ ] 칸 번호·제목이 덱 눈표와 같다
- [ ] 예상 칸이 결과 칸보다 앞에 있다
- [ ] 숫자로 적을 자리에 단위가 적혀 있다 (cm · mm · 초 · 회)
- [ ] 이다체 평서형이다
- [ ] PDF 가 A4 로 나오고 잘린 칸이 없다
- [ ] HTML 과 PDF 를 같은 이름으로 `활동지/` 에 두었다
