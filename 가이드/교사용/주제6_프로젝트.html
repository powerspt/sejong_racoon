좌표와 작업 공간 — 주제 1~3

무엇을 먼저 할지 정하면 시간이 달라진다. 이동이 비싸다는 것을 숫자로 안다.

STOP = False  # 비상정지 플래그

def on_key(k):  # 스페이스는 정지, q 는 종료
    global STOP
    if k == " ": STOP = True

def step(cell, label, score):
    if STOP:
        return "정지"
    if score < 0.55:  # ② 못 알아들었다
        return "정지"  # 기본값은 움직이지 않는 것
    x, y, z = cell_to_xyz(cell)
    if not can_move_to(x, y, z):  # ③ 범위 밖
        return "범위 밖 — 보내지 않음"
    move_to(x, y, z)
    return "이동 %s" % cell

가까운 칸에 놓느라 한 번 수직으로 선 뒤, 그다음 수에서도 계속 수직을 썼다. 먼 칸(반경 17.9cm)은 수직으로 닿는 한계의 97% 라 팔이 거의 다 펴졌고, 다 편 팔이 가장 많이 처졌다.

이렇게 풀었다

빈손일 때는 칸에 맞는 각도부터 고르고, 닿는 한 더 높이 띄워 건너가게 했다.

건너갈 때 가장 낮았던 높이 (B4 3장)전후
집게 끝5.6cm8.2cm

우리 프로젝트에서는

계산은 '갈 수 있나' 만 본다. '얼마나 아슬아슬한가' 는 따로 본다 — 쓰는 칸이 도달 한계에 몇 % 까지 다가가는지 적어 둔다.

10B4 매트를 깔았는데 A3 칸으로 갔다

무슨 일이

팔은 멀쩡히 움직이는데 칸 이름이 한 칸씩 밀렸다. A3 기준 C2 로 보내면 B4 매트에서는 B2 였다.

왜

편집기에서 F5 로 돌리면 용지 설정이 기본값 A3 로 떨어졌다. 두 격자는 칸 간격이 같아서 화면만 봐서는 못 잡는다.

이렇게 풀었다

기본값을 없애고, 시작할 때 어떤 작업 지도를 쓰는지 묻는다. 첫 칸 이름을 찍어 매트와 대조한다.

우리 프로젝트에서는

파일 맨 위 설정 칸에서 작업 지도(A3 / B4)부터 확인한다. 조용한 기본값을 믿지 않는다.

11펜을 안 물리고 돌렸더니 집게가 바닥을 긁었다

무슨 일이

'펜을 물리고 Enter' 라는 안내만 보고 그냥 Enter 를 눌렀다. 팔이 그대로 내려와 집게 끝이 책상을 긁었다.

왜

사람이 손으로 하는 준비를 input() 한 줄로 적어 두면 그냥 지나가진다. 게다가 z 는 집게 끝 높이인데, 펜 끝 높이로 착각해 너무 낮은 값을 적어 두었다.

이렇게 풀었다

팔을 펜 물리는 자세(z = 3.0)로 보내 벌린 채 기다리게 했다. 사람은 펜을 종이에 닿을 때까지 내리고 잡는다 — 물린 길이가 저절로 맞는다.

우리 프로젝트에서는

빠뜨리면 기계가 다치는 준비는, 로봇이 그 자세로 가서 기다리게 만든다. 재야 하는 값은 재지 않아도 되게 자세를 바꿀 수 있는지 먼저 본다.

12다 쓰고 Home 으로 갈 때 펜이 종이를 긁었다

무슨 일이

그리기를 마치고 home() 을 부르자 펜이 종이 위를 쓸고 지나갔다.

왜

네 관절이 한꺼번에 돌면서 손목이 수직에서 수평으로 휘었다. 집게보다 4cm 아래 매달린 펜은 그 호를 따라 1.22cm 까지 내려왔다.

이렇게 풀었다

① 제자리에서 곧게 올리고 ② 손목을 되돌린 뒤 ③ Home 으로 간다. 펜 끝 최저가 2.44cm 로 올라갔다.

우리 프로젝트에서는

공구가 집게보다 아래로 나와 있으면, 손목을 돌리는 동작 하나하나가 그 길이만큼의 호다.

시행착오에서 나온 점검표

로봇에 붙이기 전, 활동지 ⑤칸(가상 모드)을 채우며 아래를 한 번씩 본다.

  • 쓰는 칸마다 집는 높이와 다가가는 높이에 설 수 있는가 — can_move_to 로 미리 묻는다.
  • 쌓는 칸은 다가가는 높이가 탑 꼭대기보다 높은가.
  • 동시에 블록이 놓이는 칸끼리 좌우로 8cm 이상 떨어져 있는가 (앞뒤는 괜찮다).
  • 블록을 쥔 채 손목이 돌아가는 순간이 있는가.
  • 쓰는 칸이 그 기울기의 도달 한계에 몇 % 까지 다가가는가 — 90% 를 넘으면 더 띄우거나 칸을 옮긴다.
  • 가상 모드로 확인한 것과 실기기로 확인한 것을 섞어 적지 않는다. 계산만으로는 안 보이는 것이 실제로 있었다.
