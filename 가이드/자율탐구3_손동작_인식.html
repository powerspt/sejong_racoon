손동작 인식

사물이 아니라 사람을 본다

자율 탐구 — 손동작 인식 자율 탐구 ③ · hand_tracker.py

무엇을 하나

손에 점 스물한 개가 붙는다. 점 사이의 거리로 핀치·주먹을 판단하고, 상태 전이도를 먼저 그린 뒤 코드로 옮긴다.

프로젝트에 어떻게

접근성 보조 주제에 쓴다. 활동지 ④칸 명령표의 입력이 손 모양이 된다 — 어떤 모양이 어떤 동작을 부르는지 적는 그 표다.

무엇이 필요한가

웹캠과 MediaPipe. vision/hand_tracker.py 로 점을 보고, gesture_control.py 맨 위를 로봇없이 = True 로 두고 먼저 돌린다.

어디서 막히나

주먹을 1초 쥐면 명령이 수십 번 나간다. 연타를 막는 규칙을 손수 넣어야 한다 — 인식보다 그 뒤가 어렵다.

docs/손동작_안내.md

왜 하나

100분 × 2노트북 웹캠학생용/손동작_설치_도우미.bat모델 8.4MB (자동)자율 탐구 ② 을 먼저

자율 탐구 ② 의 검출기는 상자 하나와 이름표를 돌려줬다. 손 인식기는 점 21개의 좌표를 돌려준다.

좌표가 나오면 규칙을 우리가 만들 수 있다 — 손가락 두 개가 가까운가, 손이 화면 어디에 있는가.

여기서부터 오작동은 사람에게 간다. 그래서 인식보다 인식 뒤의 설계가 더 중요해진다.

1손에 점이 붙는 것을 본다

설치는 학생용/손동작_설치_도우미.bat 더블클릭 한 번이면 된다.

python vision/hand_test.py

# 키
#   n  점 번호 켜기 / 끄기
#   g  명령 칸 켜기 / 끄기
#   s  지금 화면을 사진으로 저장
#   q  종료

이렇게 되면 맞다

손을 보여 주면 점 21개와 뼈대가 그려진다. n 을 누르면 번호가 보인다.

0 은 손목, 4 · 8 · 12 · 16 · 20 이 각 손가락 끝이다.

손을 앞뒤로 움직이면 화면 속 손 크기(span)가 커지고 작아진다.

막히면

창이 안 뜬다 — 카메라 번호를 바꾼다 (vision/config.py).

모델을 못 찾는다 — 처음 한 번은 자동으로 내려받는다. 인터넷을 확인한다.

2손 모양과 확신도를 적어 본다

tracker.read(frame) 이 돌려주는 값이 무엇인지 눈으로 확인한다.

from hand_tracker import HandTracker, read_hand_frame

tracker = HandTracker()        # 모델을 불러온다 (처음 한 번만)
sig = tracker.read(frame)      # 화면 한 장 -> 손 정보

sig.found       # 손이 보이는가
sig.gesture     # 손 모양 이름 (Closed_Fist, Victory ...)
sig.score       # 얼마나 확신하는가 (0~1)
sig.palm_x/y    # 손바닥 위치 (0~1 로 정규화)
sig.landmarks   # 점 21개의 좌표

이렇게 되면 맞다

또렷한 모양에서는 score 가 0.9 가까이 나온다.

애매하게 쥐면 이름이 왔다 갔다 하고 score 가 흔들린다 — 그 구간이 문제다.

3코드보다 먼저 상태 전이도를 그린다

주먹을 1초 쥐고 있으면 명령이 몇 번 나갈까? 초당 30장이면 서른 번이다.

그래서 "모양이 바뀌는 순간"만 명령으로 치는 규칙이 필요하다. 종이에 상태(대기 · 쥠 · 실행 · 잠금)와 화살표를 먼저 그린다.

이렇게 되면 맞다

그림에 "같은 모양이 N 프레임 이어질 때만 바뀐다", "실행 뒤 0.8초는 잠근다" 같은 숫자가 적혀 있으면 됐다.

막히면

그리기 전에 코드부터 쓰면 거의 반드시 연타 문제에 걸린다. 그림이 먼저다.

4로봇 없이 먼저, 그다음 로봇으로

가상 모드로 순서를 맞춘 뒤 로봇을 연결한다. 주제 4 의 가짜 팔이 여기서도 쓰인다.

python vision/gesture_control.py --dry-run
# 콘솔에 찍힌 명령 순서가 설계한 전이도와 같은지 대조한다

python vision/gesture_control.py        # 통과한 뒤에만

이렇게 되면 맞다

주먹을 쥐었다 펴면 명령이 한 번만 찍힌다.

손이 사라지면 아무 명령도 안 나간다 — 기본값은 정지다.

막히면

명령이 연달아 찍힌다 — 3단계의 잠금 시간을 늘린다.

로봇을 붙이기 전에 비상정지를 먼저 확인한다. 스페이스가 정지, q 가 종료다.

숫자로 재기

제스처마다 열 번씩 해 보고 몇 번 알아듣는지 적는다. 사람마다 다르게 나오는 것이 이 주제의 핵심 관찰이다.

손 모양내가 한 횟수알아들은 횟수잘못 알아들은 것
주먹 (Closed_Fist)10
손바닥 (Open_Palm)10
브이 (Victory)10
핀치 (엄지+검지)10

옆 사람과 숫자를 견준다. 손 크기와 피부색, 조명에 따라 달라진다.

프로젝트에 붙이기

접근성 보조 주제에 쓴다. 활동지 ④칸의 명령표가 "어떤 손 모양이 어떤 동작을 부르는가" 가 된다.

인식률이 낮은 모양을 위험한 동작(집기·놓기)에 배정하지 않는다 — 그 이유를 명령표에 한 줄로 적는다.

성공 기준 예 — "다섯 개를 전부 손으로만 옮긴다 · 손을 한 번도 쓰지 않고".
