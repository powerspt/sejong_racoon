# 라쿤봇 설치 도우미 — 동작과 예상 출력

> 대상 파일 : `학생용/라쿤봇_설치_도우미.bat`
> 목적 : PATH 가 없어 `python`, `pip` 가 안 되는 PC 에서도 파이썬을 찾아
> `roboid` 를 설치하고, **BLE 동글이 COM 포트로 잡히는지까지** 확인한다.
>
> 아래 출력은 모두 **실제로 실행해 받은 것**이다 (2026-10-07, Windows 11, Python 3.13.12).

---

## 1. 한눈에 보기

```
더블클릭
  │
  ├─ [준비]  폴더 위치 저장 → 코드 페이지 949 고정
  │
  ├─ [1/5] 파이썬 찾기 ─── py 실행기 → PATH의 python → 설치 폴더 검색
  │            │                               (못 찾으면 python.org 열고 종료)
  │            └─ 실제 폴더(PYDIR)와 버전 기록
  │
  ├─ [2/5] pip 확인 ────── 없으면 ensurepip
  │
  ├─ [3/5] roboid 설치 ─── import 먼저 확인 → 없을 때만 설치
  │                        "설치파일" 폴더가 있으면 오프라인
  │
  ├─ [4/5] 설치 확인 ───── import roboid, serial + 버전 출력
  │
  ├─ [5/5] 동글 확인 ───── COM 포트 목록 (pyserial)
  │
  ├─ (질문) 주제 6 이후 패키지 설치 여부
  ├─ (질문) PATH 등록
  │
  └─ 코드 페이지 복구 → 종료 (성공 0 / 실패 1)
```

기본 아이디어는 원본과 같다 — **`pip` 대신 `python -m pip`.** PATH 가 없어도 파이썬 실행 파일 위치만 알면 설치할 수 있다.

**이 프로젝트에서 달라진 점**

| 추가 | 이유 |
|---|---|
| **[5/5] COM 포트 확인** | `roboid` 가 `pyserial` 을 함께 끌고 온다. 설치 직후 바로 동글을 확인할 수 있다 |
| 주제 6 이후 패키지를 **질문으로** 분리 | 주제 1 에는 `roboid` 만 필요하다. opencv·mediapipe·vosk 는 용량이 크다 |
| `/full` 옵션 | 교사가 한 번에 전체를 깔 때 |

**확인할 줄 네 개**

| 줄 | 정상 | 이상하면 |
|---|---|---|

| `준비 완료` | 끝까지 왔다 | 중간에 `[실패]` 로 멈췄다 |

## 4. `pip install roboid` 를 직접 쳤을 때

bat 없이 터미널에서 할 때도 보이는 것이 같다.

### 성공 — 처음

```
> python -m pip install roboid
Collecting roboid
  Downloading roboid-1.7.11-py3-none-any.whl.metadata (618 bytes)
Collecting pyserial (from roboid)
  Downloading pyserial-3.5-py2.py3-none-any.whl.metadata (1.6 kB)
Downloading roboid-1.7.11-py3-none-any.whl (115 kB)
Downloading pyserial-3.5-py2.py3-none-any.whl (90 kB)
Installing collected packages: pyserial, roboid

Successfully installed pyserial-3.5 roboid-1.7.11
```

### 성공 — 이미 있을 때

```
> python -m pip install roboid
Requirement already satisfied: roboid in c:\users\...\site-packages (1.7.11)
Requirement already satisfied: pyserial in c:\users\...\site-packages (from roboid) (3.5)
```

**이것도 성공이다.** 학생들이 "설치가 안 됐다"고 착각하는 1번 지점이다. `already satisfied` 는 **이미 되어 있다**는 뜻이다.

### 확인 명령

```
> python -c "import roboid, serial; print('roboid', roboid.__version__, '/ pyserial', serial.__version__)"
roboid 1.7.11 / pyserial 3.5
```

```
> python -m pip show roboid
Name: roboid
Version: 1.7.11
Summary: Python Package for Hamster, Hamster-S, Turtle, Albert Ai, Zerone, Beagle, and Raccoon
Author: Kwang-Hyun Park
Author-email: akaii@kw.ac.kr
Location: C:\Users\user\AppData\Local\Programs\Python\Python313\Lib\site-packages
Requires: pyserial
Required-by:
```

`Location` 을 눌러 보게 하면 좋다 — **설치는 그 폴더에 파일을 복사하는 일**이라는 것이 보인다.

## 5. 실패 출력과 원인

| 출력 | 원인 | 대처 |
|---|---|---|
| `'python'은(는) 내부 또는 외부 명령...` | PATH 에 파이썬이 없다 | bat 을 쓴다. 또는 `py -3 -m pip install roboid` |
| `No module named pip` | pip 누락 | `python -m ensurepip --upgrade` |
| `WARNING: Retrying ... Connection broken` | 인터넷 차단 | 학교망 방화벽. 오프라인 설치로 |
| `Could not find a version that satisfies the requirement roboid` | 오타이거나 인터넷 차단 | 패키지 이름은 `roboid` (`robiod` 아님) |
| `ERROR: Could not install packages due to an OSError: [WinError 5]` | 권한 | 관리자 터미널 또는 `--user` 추가 |
| `Defaulting to user installation because normal site-packages is not writeable` | 경고일 뿐 | 정상 설치된다. 그냥 진행 |
| `ModuleNotFoundError: No module named 'roboid'` (설치 후) | **설치한 파이썬과 실행하는 파이썬이 다르다** | 아래 참조 |

### 가장 흔한 함정 — 파이썬이 두 개

설치는 성공했는데 `import roboid` 가 안 되면 거의 이 경우다.

```
> python -c "import sys; print(sys.executable)"
```

이 경로와 `pip show roboid` 의 `Location` 이 같은 파이썬을 가리켜야 한다. 다르면 IDE 의 인터프리터를 맞춘다 — VS Code 는 `Ctrl+Shift+P` → `Python: Select Interpreter`.

## 6. 오프라인 설치 (학교망이 막혔을 때)

교사 PC 에서 미리 받는다. **학생 PC 와 같은 파이썬 버전**에서 받아야 맞는 파일이 내려온다.

```
python -m pip download roboid -d 설치파일
```

`설치파일` 폴더를 bat 옆에 두면 bat 이 알아서 쓴다. 그때 [2/5] 뒤에 한 줄이 더 나온다.

```
     설치파일 폴더를 찾았습니다 - 인터넷을 쓰지 않습니다
```

주제 6 이후 패키지까지 오프라인으로 하려면 양이 커진다 (mediapipe 포함 수백 MB).

```
python -m pip download -r requirements.txt -d 설치파일
```

## 7. 고칠 때 지켜야 할 것

원본 bat 의 규칙을 그대로 따른다.

1. **인코딩 CP949, 줄바꿈 CRLF 로 저장한다.** UTF-8 로 저장하면 한글이 깨진다
   - VS Code : 오른쪽 아래 인코딩 → Save with Encoding → Korean (EUC-KR)
2. `( … )` 블록 안의 `echo` 에는 **따옴표 밖 괄호를 쓰지 않는다.** 블록이 조기에 닫힌다
   - 그래서 이 파일의 안내 문구가 `설치합니다 - 인터넷을 쓰지 않습니다` 처럼 괄호 없이 되어 있다
3. `%~dp0` 대신 맨 위에서 저장한 `%HERE%` 를 쓴다
4. 설치는 항상 `%PY% -m pip …`
5. 새 패키지는 **import 로 먼저 확인 → 없을 때만 설치**
6. 라벨과 임시 파일 이름은 **영문**으로 둔다 (`:END`, `racoonbot_pydir.txt`)

### python -c 안의 한글

[5/5] 의 COM 포트 출력은 `python -c` 안을 **ASCII 로만** 썼고 한글 안내는 batch `echo` 로 뺐다. 코드 페이지가 섞인 환경에서 `python -c` 인자의 한글이 깨질 수 있어서다. 새 확인 단계를 넣을 때도 같게 한다.
